# Site Plan
## Home Page
**Goal:** Introduce sites’s purpose, catch users attention, make them interested enough to keep looking
### Structure
- **Navigation:** Title (left), navigation and social links (right)  
- **Hero:** Full-viewport image, semi-transparent dark overlay, text overlay  
- **Intro:** Hook, “Shaping how students think, not just what they learn”
-**Lead-in:** Supporting text, “Discover how being an LA can benefit you”
-**Call-to-Action**”Explore” button takes then to the About page

##About
**Goal:** Explains more about what an LA is, and how it can benefit the viewer, meant to look interesting and keep their attention
###Structure
- **Navigation:** Title (left), navigation and social links (right)
-**Header:** Image, semi-transparent dark overlay, text overlay 
-**Intro:** Explaining what an LA is and what the program is, colored text
- **Main Content:** 4 Cards featuring core-strategies that LA’s learn. Background image with gradient color overlay to make text overlay readable

##Info
**Goal:** Information on who users should contact if they are interested in the program or have questions
###Structure
- **Navigation:** Title (left), navigation and social links (right)
-**Header:** Image
-**Intro:** Meet the Director
- **Main Content:** Image of Director (left) Information (right)
-**Call-to-action:** Contact button that leads to email

##Stories
**Goal:** “interview” with an LA (me) to explain more about program and experience, encouragement for users
###Structure
- **Navigation:** Title (left), navigation and social links (right)
- **Hero:** Full-viewport image, semi-transparent dark overlay, text overlay 
-**Main Content:** Question
-**Supporting Content:** Answer
